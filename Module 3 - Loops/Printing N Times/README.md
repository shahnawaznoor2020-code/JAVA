## Java Practice Question – Print N Times

This folder contains a Java program that solves a **basic practice question** demonstrating how to use loops to print a specific statement or number sequence $N$ times.

It is intended for beginners to strengthen their understanding of **core Java fundamentals**, specifically dynamic loop boundaries, iteration, and console output.

## 📌 Program Overview

The program in this folder covers the following practice concepts:

* Setting up a basic Java class and `main` method structure.
* Utilizing a `for` or `while` loop to execute a block of code repeatedly for a specified number of times ($N$).
* Understanding loop initialization, condition evaluation against a variable bound, and incrementation.
* Printing output to the console sequentially using `System.out.println()`.

The program typically takes an integer value $N$ and iterates exactly that many times, executing the print statement during each iteration.

## 🧪 Code Functionality

The program demonstrates:

### Iteration Logic

* **Variable Boundary**: Defines an upper limit $N$ which dictates how many times the loop will run.
* **Initialization**: Sets a starting counter variable, typically `int i = 1;`.
* **Condition**: Checks if the counter has reached the boundary $N$ before executing the loop body (e.g., `i <= n`).
* **Increment**: Increases the counter variable by 1 after each successful print statement (`i++`).

The program is written in a **simple and readable format**, making it a perfect exercise for grasping how iterative control flow works with dynamic limits.
