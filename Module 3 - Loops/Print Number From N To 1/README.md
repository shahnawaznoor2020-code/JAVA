## Java Practice Question – Print Numbers From N to 1

This folder contains a Java program that solves a **basic practice question** demonstrating how to print numbers in reverse order from a user-defined number $N$ down to $1$.

It is intended for beginners to strengthen their understanding of **core Java fundamentals**, specifically reverse iteration, decrement operators, and handling user input.

## 📌 Program Overview

The program in this folder covers the following practice concepts:

* Setting up a basic Java class and `main` method structure.

* Reading a starting integer $N$ from the user (commonly using the `Scanner` class).

* Utilizing a `for` or `while` loop to iterate backward from $N$ down to $1$.

* Understanding loop initialization with a dynamic variable, termination conditions, and decrementation (`--`).

* Printing the countdown sequence to the console using `System.out.println()` or `System.out.print()`.

The program takes an integer input $N$ and prints every integer decrementally until it reaches $1$.

## 🧪 Code Functionality

The program demonstrates:

### Reverse Iteration Logic

* **User Input**: Prompts the user to enter an integer value $N$ to serve as the starting point of the sequence.

* **Initialization**: Sets the loop counter variable to the user-provided starting number (`int i = n;`).

* **Condition**: Evaluates whether the counter is still greater than or equal to $1$ (`i >= 1`) before executing each iteration.

* **Decrement**: Decreases the counter variable by $1$ after printing the current value (`i--`).

The program is written in a **simple and readable format**, making it a great exercise for understanding reverse traversal and loop termination boundaries.
