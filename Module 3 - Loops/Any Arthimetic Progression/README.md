## Java Practice Question – Arithmetic Progression Generator

This folder contains a Java program that solves a **basic practice question** demonstrating the use of loops to generate and print a mathematical Arithmetic Progression (AP) series based on specified parameters.

It is intended for beginners to strengthen their understanding of **core Java fundamentals**, specifically loop iteration, variable updating, and basic arithmetic operations.

---

## 📌 Program Overview

The program in this folder covers the following practice concepts:

- Setting up a basic Java class and `main` method structure.
- Using the `Scanner` class to read user input (such as the number of terms, starting number, or common difference).
- Using a `for` or `while` loop to iterate and generate the sequence.
- Applying the mathematical logic of an Arithmetic Progression, where each subsequent term is generated by adding a constant difference to the previous term.

The program calculates the sequence sequentially and prints the series clearly in the console.

---

## 🧪 Code Functionality

The program demonstrates:

### Sequence Generation Logic
- **Initialization**: Setting up the starting term of the progression.
- **Looping**: Using a loop to iterate for the desired number of terms ($n$).
- **Arithmetic Update**: Inside the loop, printing the current term and then updating it by adding the common difference (e.g., `currentTerm += commonDifference`).

### User Interaction
- Prompts the user for necessary sequence parameters.
- Reads the inputs using the `Scanner` class.

The program is written in a **simple and readable format**, displaying the step-by-step progression of the sequence.
